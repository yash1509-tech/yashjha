# Student Record Management System (VITYARTHI) 🎓

A console-based Python application for managing student academic records and automating grade computation[span_0](start_span)[span_0](end_span). Developed as part of the **CSE Project - Vityarthi** at **VIT Bhopal University**[span_1](start_span)[span_1](end_span).

---

## 📌 Project Overview

The **Student Record Management System** is a menu-driven CLI tool built to eliminate manual, error-prone grade calculation[span_2](start_span)[span_2](end_span). It provides a single session in-memory workflow to record, calculate, search, display, and manage student performance data efficiently[span_3](start_span)[span_3](end_span).

### Key Features
- **Automated Grade Computation:** Calculates total marks, percentage, letter grades ($A+$ through $E$, or $F$), and overall Pass/Fail status automatically upon entry[span_4](start_span)[span_4](end_span).
- **Subject-Wise Fail Override:** Implements a strict passing policy where scoring below 35 in any subject results in an automatic $F$ grade regardless of overall average[span_5](start_span)[span_5](end_span).
- **CRUD Operations:** Supports adding, listing, searching, and deleting records via roll number[span_6](start_span)[span_6](end_span).
- **Dependency-Free:** Built strictly using pure Python standard constructs—no external packages required[span_7](start_span)[span_7](end_span).
